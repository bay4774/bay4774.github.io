# 六方向基础讲义设计

用户在2026-10-17明确指定六方向：大模型、具身智能、仿生机器人头、物理约束、Agent、伴语手势生成；随后明确不固定章数，应尽可能详细、便于理解。

## 编写原则

- 读者已掌握00–79章公共基础，引用具体先修，不重新堆叠公共课程；领域对象与新术语仍从直觉解释。
- 以概念依赖而非固定数量拆章。每章有问题、定义与符号、推导中间步、完整算例、边界、自测及步骤答案、可复现实验流程与出口。
- 章数和教学次序由内容metadata维护；`direction-curriculum.json`只定义六方向名称、标识与简介。`directionChapter`表达教学顺序，URL保持稳定，新增讲义不要求改变既有URL。
- 当一个主题有多个相互依赖的新对象时，拆分后保留明确链接。难章允许延长学习时间，不用统一周数约束所有方向。
- 解释理论、数值复算、合成实验设计、真实系统结果的证据范围；未运行的实验不描述为已运行。
- 参考来源使用实际核验的作者教材、原始论文或官方文档；公开正文用原创说明与合成案例。
- 方向课继续遵守`docs/foundations/TEACHING_STANDARD.md`与`CONTENT_POLICY.md`的通用教学与私有记录隔离规则。

## 入口和导航

- 总入口：`src/content/notes/direction-foundations.mdx`，动态列出六方向所有已发布章节。
- 讲义列表：`DirectionStart.astro`提供按方向入口；单章`DirectionNav.astro`按真实metadata提供前后章。
- 各方向审读分别在本目录记录，统稿的工程验证与抽查结果另记`INTEGRATION_REVIEW.md`。

## 教学设计与实际学习分开

讲义数量、内容审查和工程检查是教材状态，不能据此登记个人已经完成学习。个人作答、成绩、错题和进度沿用项目既定`.private/research-foundations/records/`，不创建公开的个人进度页面。
