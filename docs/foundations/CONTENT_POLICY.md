# 40 周课程内容与私人学习成果

根据用户2026-10-16的进一步说明，讲义以独立主题章组织，像00、01那样逐章解释；40周只是一张阅读路径，列出每两周读哪几章。不能把两周安排当成一篇讲义的单位。

当前为00–79章，每章保留先修、概念解释、推导、例题、自测及参考解和后续衔接。每四章完成后回读自纠，对应阅读路径中的一个两周窗口，再进入下一组。个人学习节奏由实际作答决定。

## 教学内容

- 章节目录与先修关系：src/data/foundations-chapters.json；周次到章节的映射：src/data/foundations-curriculum.json。
- 公开讲义：src/content/notes/foundations-NN-topic.md，每个文件一章。
- 作者对教学内容的自纠记录：docs/foundations/chapter-reviews/。只检查教材，不登记个人学习成果。
- 公开演示代码：public/research-foundations/。只使用明确标注的合成数据或合法公开教学数据。
- 标准练习答案属于教学内容，可以随讲义提供；用户的实际作答与批改不放入这些位置。

## 私有学习成果

用户后续提交的作答、学习总结、成绩、错题、批改、学习进度与个性化补习反馈，统一存入 .private/research-foundations/records/。模板为同目录上一级的 learning-record-template.md。

.private/ 已被 Git 忽略，且在 Astro 内容集合和 public/ 之外。不要将它移动到网站内容目录，不要为私人记录生成网页或下载链接，也不要将其加入版本控制。保留“未报告”状态，避免把讲义完成时间当作学习完成时间。

若私人反馈指出公共讲义的概念缺口，修订时提炼为通用说明和新的例子。个人原始成果与批改继续私存。

## 两周自纠

每个记录包括：四个独立章节的先修与已定义符号，拆分后是否自足，公式和例题的数值检查，练习及答案是否匹配，实际发现的问题与修正，下一章所需的出口能力及范围。每周时间预算在阅读路径中维护。没有发现具体问题时列出实际核验对象，不虚构“发现后修正”。

内容自查不是个人学习验收，也不替代未来的读者反馈。所有章节备好后，仍按实际学习成果决定是否加例子、回补或延长某一阶段。原两周合订稿、旧起步稿和旧检查记录可移入docs/foundations/archive/，不继续作为公开讲义列表展示；旧URL通过兼容跳转保留。

## 发布

线上主页仅发布公共教学内容和教学代码。发布前执行构建、站内链接检查以及私人记录隔离检查，确认版本提交和发布产物均不含个人学习记录。个人笔记、作答、批改和实际学习进度继续只保存在本地。目录中的私有检查标记不含个人数据，用于发现意外复制。
