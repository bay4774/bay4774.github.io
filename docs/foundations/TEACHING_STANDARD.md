# 入门讲义的内容维护标准

本标准用于当前00–79章公共主干及其后续修订。2026-10-16根据用户的整体教学审查要求补充。这里约束公开教材，不记录学习者完成状态。

1. 每章给出本章问题、具体先修、定义与对象范围。先修是工具关系，主题切换可以与相邻章节没有直接依赖。
2. 新符号首次使用时说明读法、对象/维度及含义。统一术语：方差与标准差、密度与概率、导数与梯度、残差与解误差等不可混写。
3. 公式区分定义、已经推导的结果、有条件引用的定理和经验规则。全局/局部、已知/未知、独立/相关、固定设计/随机设计等条件与结论一起出现。
4. 核心算例至少展示从输入建模、替换定义、运算到结果核验的过程。关键代数步、矩阵形状、坐标和单位不能仅用“显然”跳过。
5. 在容易过度推广处给一个边界或反例，明确反驳的是哪条结论。数值复算支持例子，不冒充一般证明。
6. 每章提供独立自测和可回查的步骤答案。20组跨章复习另用于检索与迁移；核心与迁移层次分开，不能把第二遍定理证明当初学者进入下一章的无条件门槛。
7. 讲义按章节组织，40周仅分配阅读。难章允许顺延，补充课程和全部论文不叠加为每周必做；正文阅读分钟数不当作掌握用时。
8. 图示服务概念。数字、坐标、面积、颜色含义与正文一致，提供替代文字；示意区间或模拟图不得伪装为覆盖率或实测结果。
9. 改动概念后检查使用它的后续章节、先修导航和复习答案；修正题目时同步更新答案、独立复算及审查记录。
10. 出版/作者/机构来源用于核验有疑义事实和定位补充资料。公开正文用原创解释与合成案例；个人作答、批改、成绩和进度只保存在项目既定的`.private/research-foundations/records/`私有目录，不进入`src/content`或`public`。

第10条的位置规则以`CONTENT_POLICY.md`为准：私人内容保存在`.private/research-foundations/records/`；其父目录已由Git忽略。任何“私下保存”都不表示已经收到了用户尚未提交的成果。
